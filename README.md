Nitwit Tavern Redesign is a SillyTavern extension that changes how your chats look. It adds a header banner above the chat for each character, using either an image gallery or a looping YouTube video, with adjustable height, crop, and spacing.
Banners work in single-character chats only. It also styles the AI and user profile pictures separately: either as a faded backdrop behind the message text, or as a free-floating pop-out image you can place anywhere on screen.
Everything lives in one menu in the Extensions panel, and settings save automatically.
